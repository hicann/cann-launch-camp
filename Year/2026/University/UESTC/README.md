# 电子科技大学CANN创新实训基地

## 活动介绍
电子科技大学 CANN 创新实训基地，是校企依托昇腾 CANN 技术生态，面向信息及交叉学科本硕博学生，通过共建课程、实训实践、科研竞赛等合作，搭建产教融合育人平台，专门培养具备昇腾算力工程实践、系统开发与技术创新能力的 AI 基础设施专业人才。

## 提交规范

### 命名规范
- **用户目录**：使使用 gitcode 用户名
- **任务目录**：使用任务名称

### 提交步骤
1. 在活动文件夹下创建以 **gitcode用户名** 命名的文件夹
2. 在用户名文件夹下创建以 **任务名称** 命名的文件夹
3. 按照任务要求提交贡献内容
4. 提交 Pull Request 到本仓库
