# GELU 算子赛题 — 项目约束文档

## 一、文件修改限制

### 1.1 禁止修改的文件

以下文件为赛题模板提供的构建配置，**严禁修改**：

| 文件路径 | 说明 | 禁止修改原因 |
|----------|------|-------------|
| `CMakeLists.txt` | 根目录 CMake 构建配置 | 竞赛平台使用统一构建环境 |
| `op_host/CMakeLists.txt` | Host 侧 CMake 构建配置 | 算子注册与编译流程固定 |
| `op_kernel/CMakeLists.txt` | Kernel 侧 CMake 构建配置 | 核函数编译与链接流程固定 |

### 1.2 允许修改的文件

以下文件为算子实现源文件，选手可在赛题约束范围内自由修改：

| 文件路径 | 说明 | 行数参考 |
|----------|------|---------|
| `op_host/gelu.cpp` | Host 侧 Tiling 实现 | ~94 行 |
| `op_kernel/gelu.cpp` | Kernel 侧核函数实现 | ~180 行 |
| `op_kernel/gelu_tiling.h` | Tiling 结构体定义 | ~10 行 |
| `op_kernel/tiling_key_gelu.h` | TilingKey 模板定义 | ~14 行 |

### 1.3 其他文件

| 文件路径 | 说明 | 状态 |
|----------|------|------|
| `README.md` | 项目说明 | 可读，无需修改 |
| `任务.txt` | 赛题描述（含示例） | 仅参考，不参与构建 |

## 二、CMakeLists.txt 模板内容（冻结）

### 2.1 根目录 `CMakeLists.txt`

```cmake
cmake_minimum_required(VERSION 3.16.0)
project(custom_project)
find_package(ASC REQUIRED)
set(ASCEND_COMPUTE_UNIT ascend910b)
set(package_name custom)
npu_op_package(${package_name}
    TYPE RUN
    CONFIG INSTALL_PATH ${CMAKE_BINARY_DIR}
)
add_subdirectory(op_host)
add_subdirectory(op_kernel)
```

关键参数：

| 参数 | 当前值 | 说明 |
|------|--------|------|
| `project` | `custom_project` | 项目名称，不可修改 |
| `ASCEND_COMPUTE_UNIT` | `ascend910b` | 目标芯片 |
| `package_name` | `custom` | 算子包名，不可修改 |

### 2.2 `op_host/CMakeLists.txt`

```cmake
file(GLOB host_src ./*.cpp)

npu_op_code_gen(
    SRC ${host_src}
    PACKAGE ${package_name}
    OUT_DIR ${ASCEND_AUTOGEN_PATH}
)

npu_op_library(cust_optiling TILING ${host_src})

file(GLOB autogen_aclnn_src ${ASCEND_AUTOGEN_PATH}/aclnn_*.cpp)
set_source_files_properties(${autogen_aclnn_src} PROPERTIES GENERATED TRUE)
npu_op_library(cust_opapi ACLNN
    ${autogen_aclnn_src}
)

npu_op_package_add(${package_name}
    LIBRARY
        cust_optiling
        cust_opapi
)
```

### 2.3 `op_kernel/CMakeLists.txt`

```cmake
npu_op_kernel_sources(ascendc_kernels
    KERNEL_DIR ./
)

npu_op_kernel_library(ascendc_kernels
    SRC_BASE ${CMAKE_CURRENT_SOURCE_DIR}
    TILING_LIBRARY cust_optiling
)

npu_op_package_add(${package_name}
    LIBRARY ascendc_kernels
)
```

## 三、违规风险

修改 CMakeLists.txt 会导致以下问题：

| 风险 | 说明 |
|------|------|
| **编译失败** | 竞赛平台使用统一构建流水线，修改后可能无法通过编译 |
| **门禁拒绝** | 平台门禁会检测 CMakeLists.txt 的 md5 变化，拒绝提交 |
| **扣分/零分** | 违反赛题规则可能导致成绩作废 |

---

## 四、修改验证

在提交前，建议验证 CMakeLists.txt 未被修改：

```bash
# 检查 md5 是否与模板一致
md5sum CMakeLists.txt op_host/CMakeLists.txt op_kernel/CMakeLists.txt

# 或使用 git 检查
git diff HEAD -- CMakeLists.txt op_host/CMakeLists.txt op_kernel/CMakeLists.txt
```

## 五、允许修改的 4 个文件概览

| 文件 | 职责 | 输出 |
|------|------|------|
| `op_kernel/gelu_tiling.h` | Tiling 结构体定义 | `totalLength`、`blockLength`、`ubLength` |
| `op_kernel/tiling_key_gelu.h` | TilingKey 模板声明 | `DT_INPUT_X` (float16/float32) |

| `op_kernel/gelu.cpp` | Device 侧 GELU 计算 | GELU(x) = 0.5·x·(1+erf(x/√2)) |
