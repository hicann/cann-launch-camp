# 产业课题实践

本目录用于收纳电子科技大学 CANN 创新实训基地第一期实训课程的产业课题成果。

## 课题方向

| 方向 | 课题 | 说明 |
|------|------|------|
| 算子开发 | [GELU算子](./GELU.md) | 基于 Ascend C 实现 GELU 激活函数算子，支持 FP16 / FP32，精度与 PyTorch 对齐 |

## 提交目录结构

按以下规范创建个人目录并提交成果：

```
Industrial-Task/
├── README.md
├── GELU.md                           # GELU算子任务说明
├── {姓名}_{gitcode账号}_{任务名称}/
│   ├── README.md                     # 课题说明与运行指南
│   ├── src/                          # 源码
│   └── ...
└── ...
```

## 提交流程

详细操作步骤请参阅 [PR 提交指南](../../PR-submission-guide.md)，简要流程：

1. Fork 代码仓并克隆到本地
2. 在本地创建个人提交目录
3. 完成代码编写与自检
4. 提交 PR 等待审核

## 课题产出要求

- 源码完整可运行，附构建与运行说明
- 提供精度验证结果（与 PyTorch `torch.nn.functional.gelu` 对标）
- 所有提交需遵守 [合规要求](../README.md#合规要求)
