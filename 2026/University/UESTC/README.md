# 电子科技大学CANN创新实训基地

## 活动介绍
电子科技大学 CANN 创新实训基地，是校企依托昇腾 CANN 技术生态，面向信息及交叉学科本硕博学生，通过共建课程、实训实践、科研竞赛等合作，搭建产教融合育人平台，专门培养具备昇腾算力工程实践、系统开发与技术创新能力的 AI 基础设施专业人才。

        └── README.md                           # 产业课题提交规范、合规要求

## 提交规范

所有参与实训的学生需严格遵循本规范提交课程作业、产业课题成果及各类实践内容，目录命名、提交路径、提交流程统一标准化，禁止自定义层级与命名。

### 命名规范
- 用户目录：使用个人真实 GitCode 用户名命名，唯一标识提交人，保证成果可追溯
- 任务目录：根据当期产业课题、实训任务名称规范命名，精准对应实践内容

### 提交步骤
所有成果需提交至固定产业课题层级目录，禁止跨层级提交、随意新建文件夹，标准流程如下：
1. 进入固定路径：UESTC/First-Session/Industrial-Task/
2. 在产业课题目录下创建以 GitCode 用户名 命名的个人文件夹
3. 在个人用户文件夹内创建以 对应任务/课题名称 命名的任务文件夹
4. 在任务目录内完整提交对应课题源码、文档、使用说明、报告等全部成果内容
5. 本地自检合规、运行正常后，提交 Pull Request 至 cann-launch-camp 仓库，等待社区审核合入

## 合规要求
- 所有提交者需提前完成 CANN 社区 CLA 签署，无有效 CLA 的提交无法通过机器人校验与合入
- 代码需符合 CANN 社区编码规范，新建文件需补充标准版权声明，引用第三方开源代码需完整登记 License 与版权信息
- 提交成果需保证完整可用，包含可运行源码、配套文档、操作说明，杜绝空提交、残缺提交
