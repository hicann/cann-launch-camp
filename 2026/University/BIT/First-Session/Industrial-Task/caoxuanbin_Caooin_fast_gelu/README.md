## 2. 对照题目要求的实现说明

实现公式如下：

```text
y = x * exp(0.851 * (x - abs(x))) / (1 + exp(-1.702 * abs(x)))
```

实现特点：

- `x >= 0` 时，分子指数项为 `exp(0)`，输出接近输入值
- `x < 0` 时，分子指数项严格衰减，输出趋近于 `0`
- 两个指数项的指数都不大于 `0`，避免中间指数溢出
- 内部以 `float32` 执行 `float16` 计算，再回写到输入 dtype，兼顾稳定性和输出约束
- 逐元素计算，天然保持任意维度输入的形状不变

与题目约束的对应关系：

- 数据类型约束：仅接受 `float16` / `float32`
- 形状约束：输出 shape 与输入 shape 完全一致
- 非对齐约束：测试包含 `31`、`33` 等非 32 整倍数长度
- 高维约束：测试包含 1D、2D、3D、4D 和带 batch 的高维张量
- 边界约束：测试覆盖 `N=1`、`N=10000`、零值、极大值、极小值、空张量

精度阈值：

- `float32`: `rtol=1e-4`, `atol=1e-4`
- `float16`: `rtol=1e-3`, `atol=1e-3`

## 6. 数值稳定性说明

题目要求避免指数计算溢出。这里的实现满足这个要求：

- 分母指数项为 `-1.702 * abs(x)`，始终小于等于 `0`
- 分子指数项为 `0.851 * (x - abs(x))`，也始终小于等于 `0`
- 实现里对两个指数参数再次用 `minimum(..., 0.0)` 做保护，避免异常输入下出现正指数

因此，这个实现不会因为 `exp(large_positive)` 导致上溢。
