## 3. 功能说明
本项目实现昇腾AI芯片 FastGelu 激活算子，分为两部分：
1. op_host：CPU侧算子注册、参数校验、输入输出维度处理逻辑
2. op_kernel：NPU设备侧核心计算内核，实现FastGelu数学运算加速
