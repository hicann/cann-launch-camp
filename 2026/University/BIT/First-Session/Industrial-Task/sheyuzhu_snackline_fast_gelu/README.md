\# FastGelu 算子实现说明



\## 1. 实现概述



本实现基于昇腾 Ascend C 编程语言，在 Ascend 910B NPU 上实现了高性能、高精度的 FastGelu 激活函数算子。



\### 1.1 算子公式

output = x \* exp(0.851 \* (x - |x|)) / (1 + exp(-1.702 \* |x|))



\### 1.2 数学等价形式



该公式与 `x \\\\\\\* sigmoid(1.702 \\\\\\\* x)` 数学等价，数值稳定性分析如下：



\- \*\*x ≥ 0 时\*\*：`x - |x| = 0`，分子指数项 `exp(0) = 1`，输出趋近于 x

\- \*\*x < 0 时\*\*：分子指数项 `0.851 \\\\\\\* 2x < 0`，严格衰减，输出趋近于 0

\- \*\*两个指数入参均 ≤ 0\*\*，不会产生指数上溢

\## 3. 核心设计



\### 3.1 多核不均匀切分



Host 侧根据输入数据量和可用核数，计算不均匀分片方案：



\- 前 `formerNum` 个核处理 `formerLength` 个元素

\- 后 `tailNum` 个核处理 `tailLength` 个元素

\- 每个核至少处理 64 个元素，避免小粒度调度开销

\- 当元素数少于核数时，减少启动核数，避免空跑



\### 3.2 核内 Tile 切分



\- 根据 UB 大小动态计算单次搬入处理的 tile 大小

\- 按 32 字节对齐，提升搬运效率

\- 最后一个 tile 单独处理，兼容非对齐场景



\### 3.3 UB 内存管理



使用 Ascend C 的 `TPipe` + `TQue` + `TBuf` 机制管理 UB 内存：



\- \*\*双缓冲队列\*\*：`inQueueX\\\\\\\_` 和 `outQueueY\\\\\\\_` 各分配 2 个 buffer

\- \*\*复用 yLocal 作为分母临时存储\*\*：省掉独立的 `denBuf\\\\\\\_`，减少 UB 占用

\- \*\*计算 buffer\*\*：仅需 `absBuf\\\\\\\_` 和 `numBuf\\\\\\\_` 两块



\### 3.4 数据搬运



使用 `DataCopyPad` 搬运数据，天然支持非 32 字节对齐场景，无需手动处理前导/尾部非对齐数据。



\## 4. 数值稳定性



\- 两个指数项的参数恒 ≤ 0，天然避免 `exp(large\\\\\\\_positive)` 导致的上溢

\- float16 场景下计算在 float16 类型上直接完成，满足双千分之一精度要求

\- float32 场景下满足双万分之一精度要求

\## 7. 性能优化要点



1\. \*\*双缓冲流水线\*\*：计算与数据搬运重叠，隐藏访存延迟

2\. \*\*UB 内存精简\*\*：复用 yLocal 作为分母中间值，增大 tile 粒度

3\. \*\*DataCopyPad\*\*：兼容非对齐搬运，避免逐元素处理边界

4\. \*\*动态 Tile 计算\*\*：根据 UB 大小自适应调整 tile 长度

5\. \*\*最小粒度控制\*\*：每核至少处理 64 元素，避免小粒度调度开销
