# 北京理工大学CANN创新实训基地

## 活动介绍
北京理工大学 CANN 创新实训基地，是校企依托昇腾 CANN 技术生态，面向信息及交叉学科本硕博学生，通过共建课程、实训实践、科研竞赛等合作，搭建产教融合育人平台，专门培养具备昇腾算力工程实践、系统开发与技术创新能力的 AI 基础设施专业人才。

## 培养目标
通过体系化实训课程与产业课题实践，帮助学生获得以下核心能力：

- **昇腾基础能力**：深入理解昇腾 AI 处理器硬件架构、CANN 软件栈分层设计与核心组件协作机制，掌握异构计算编程范式
- **算子开发能力**：熟练使用 Ascend C 进行自定义算子开发，具备高性能算子设计与工程实现能力
- **模型适配能力**：掌握主流模型框架（PyTorch、MindSpore 等）在昇腾平台的迁移、适配与精度对齐全流程
- **性能调优能力**：熟练运用 Profiling、调优工具链进行端到端性能分析与瓶颈优化，具备算力利用率优化经验
- **工程实践能力**：通过产业课题实战，具备需求分析、方案设计、代码实现、文档交付的完整工程交付能力

## 合规要求
- 所有提交者需提前完成 CANN 社区 CLA 签署，无有效 CLA 的提交无法通过机器人校验与合入
- 代码需符合 CANN 社区编码规范，新建文件需补充标准版权声明，引用第三方开源代码需完整登记 License 与版权信息
- 提交成果需保证完整可用，包含可运行源码、配套文档、操作说明，杜绝空提交、残缺提交
